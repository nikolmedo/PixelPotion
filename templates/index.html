Get started

Three things to set up before your first photo can be delivered.

  1. {{ icon("check" if gemini_ready else "cross") }}{{ "Done:" if gemini_ready else "To do:" }}
    Add your Gemini key

    Create a free key at aistudio.google.com/apikey. While your phone is on {{ ap_name }} it has no internet here, so switch to mobile data for a minute, copy the key, then come back.

  2. {{ icon("check" if telegram_ready else "cross") }}{{ "Done:" if telegram_ready else "To do:" }}
    Connect Telegram

    In Telegram, open @BotFather, send /newbot and copy the token it gives you. Send any message to your new bot, then ask @userinfobot for your chat ID (a number).

  3. {{ icon("check" if wifi_connected else "cross") }}{{ "Done:" if wifi_connected else "To do:" }}
    Join your WiFi

    Do this last: the camera leaves setup mode and your phone disconnects from {{ ap_name }}.
